# Структура проекта

## Сцены
- Название сцены - SampleScene.unity

## Основная игровая сцена
- Объекты на сцене: character, grass, lever, treebackround
- Экземпляры префабов: character, grass, lever, treebackround

## Игрок
- Компоненты: carry item, character anim, character hold item, player character, player controls

## Скрипты
- ScriptName: carry item (работает при взятии предметов (предмет)), character anim (анимации игрока), character hold item (работает при взятии предметов (игрок)), follow camera (движение камеры), lever (рычаг), parallax backround(движение задника), player character (персонаж), player controls (управление), the audio(звук)
