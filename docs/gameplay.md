## Физические параметры :
    1) Rigidbody 2D - компонент CharacterPlatformer(Игрок),отвечающий за реалистичную физику движения и гравитацию
    Основные параметры :
    Mass (Масса) - 10 единиц
    Gravity Scale = 0 единиц (Похоже гравитация реализована,не через Rigidbody,а в ручную через скрипт)
    Material - не указан
    2) Capsule Collider 2D - компонент CharacterPlatformer(Игрок),отвечающий за соприкосновение с другими колайдерами (другими словами хит бокс)
## Префабы:
    1) CharacterPlatformer - префаб игрового персонажа
    2) Grass - префаб переднего окружения (трава)
    3) Lever - игровой объект (рычаг),способен принимать 2 состояния (включён и выключен),похоже используется в механике головоломке,где нужно что-то открыть (соответствующей реализации обнаружено не было)
## UI:
    Пользовательский интерфейс не обнаружен
## Настройки через Inspector:
    1) Через Inspector есть возможность менять настройки физики персонажа,размер его коллайдера,натсройки поведения персонажа,настройки камеры - вцелом все компоненты объектов на сцене,и public переменные скриптов камеры и перонажа/
    2) Посредством изменения таких групп переменных как Jump,Movement в классе Player Character (компонент Character Platformer) возможно изменить движение персонажа,что повлияет на сложность игры.
